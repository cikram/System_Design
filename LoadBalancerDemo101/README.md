# Load Balancer Demo

Demonstration Spring Boot accompagnee d'une configuration Nginx dans `nginx/nginx.conf`.

## Lancer l'application

```powershell
.\mvnw.cmd spring-boot:run
```

## Tester

```powershell
.\mvnw.cmd test
```

Java 21 est requis. La configuration Nginx est a adapter selon les instances et les ports utilises localement.
